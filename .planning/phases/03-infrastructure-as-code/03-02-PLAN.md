## Цель плана 03-02 (post-pivot — Wave 2)

Развернуть `sport-stack` Ansible role, который deploy'ит containerized backend stack (8 Go services + Caddy + Postgres+TimescaleDB + Redis + NATS + MinIO — всего 13 контейнеров) на существующий prod VPS через `sport-stack.service` systemd umbrella unit. SOPS-decrypt происходит на dev workstation (`delegate_to: localhost`) и plaintext env templating на `/run/sport.env` (tmpfs, mode 0600, owner deploy) с `shred -u` в `ExecStopPost`. Migrations выполняются как separate Ansible play (`docker compose run --rm migrate`) **до** старта `sport-stack.service`. После service-up — smoke probe loop (5×30s retry на ACME issuance window).

**Purpose:** Wave 2 закрывает INFRA-01 (containerized stack под systemd umbrella) + INFRA-07 (<60min fresh-deploy timing — measured впервые на existing prod VPS, поскольку нет staging baseline per D-23). Wave 3 (Plan 03-03) после этого выполняет prod cutover + creates provider-agnostic deploy RUNBOOK + patches ROADMAP/REQUIREMENTS.

       ```yaml
       ---
       # Per CONTEXT D-12 — SOPS runs на dev workstation ТОЛЬКО.
       # Age key NEVER copied to remote VPS (D-26 — нет SOPS slot для VPS access вообще).
       #
       # Sequence:
       #   1. На controller (localhost): assemble plaintext .env content в Ansible facts via community.sops.load_vars
       #      для каждого SOPS group в sport_sops_groups (shared, mapbox, oauth).
       #   2. На remote VPS: template (ansible.builtin.template) — render merged dict to /run/sport.env
       #      with mode 0600, owner deploy, group deploy.
       #
       # Pre-flight: SOPS_AGE_KEY_FILE must point to existing file (W3 fix — HOME-explicit construct).

       - name: "Pre-flight — assert age key file exists on controller (W3 fix)"
         delegate_to: localhost
         become: false
         ansible.builtin.stat:
           path: "{{ lookup('env', 'SOPS_AGE_KEY_FILE') | default(lookup('env', 'HOME') + '/.config/sops/age/keys.txt', true) }}"
         register: age_key_stat
         failed_when: not age_key_stat.stat.exists
         tags: [sport-stack]

       - name: "Decrypt SOPS groups on controller (per CONTEXT D-12 + D-26 — 3 slots only)"
         delegate_to: localhost
         become: false
         environment:
           # W3 fix: explicit HOME construct (NOT expanduser — that path was rejected в prior plan-checker round).
           SOPS_AGE_KEY_FILE: "{{ lookup('env', 'SOPS_AGE_KEY_FILE') | default(lookup('env', 'HOME') + '/.config/sops/age/keys.txt', true) }}"
         community.sops.load_vars:
           file: "{{ playbook_dir }}/../../.secrets/{{ env_name }}/{{ item }}.yaml"
           name: "sport_secrets_{{ item }}"
         loop: "{{ sport_sops_groups }}"
         loop_control:
           label: "{{ item }}"
         no_log: true         # CRITICAL — RESEARCH Pitfall 8 (plaintext в ~/.ansible.log)
         tags: [sport-stack]

       - name: "Merge SOPS groups into single env dict on controller"
         delegate_to: localhost
         become: false
         ansible.builtin.set_fact:
           sport_env_merged: >-
             {{
               (sport_secrets_shared | default({}))
               | combine(sport_secrets_mapbox | default({}))
               | combine(sport_secrets_oauth | default({}))
             }}
         no_log: true
         tags: [sport-stack]

       - name: "Template merged env to /run/sport.env на remote (tmpfs per D-15)"
         ansible.builtin.template:
           src: sport.env.j2
           dest: "{{ sport_env_file }}"
           owner: "{{ sport_env_owner }}"
           group: "{{ sport_env_group }}"
           mode: "{{ sport_env_mode }}"
         no_log: true
         tags: [sport-stack]
       ```

       ```ini
       # /etc/systemd/system/sport-stack.service — Phase 3 D-04 docker-compose-on-systemd umbrella.
       # Wraps the 13-container production stack (8 Go services + 4 stateful + 1 gateway containerized Caddy)
       # under ONE systemd unit. Per D-15: /run/sport.env tmpfs mode 0600 owner deploy; shred on stop.

       [Unit]
       Description=Running Ecosystem backend stack (docker compose umbrella)
       After=docker.service network-online.target
       Requires=docker.service
       Wants=network-online.target

       [Service]
       Type=simple
       User={{ deploy_user }}
       Group={{ deploy_group }}
       WorkingDirectory={{ sport_install_dir }}
       EnvironmentFile={{ sport_env_file }}
       # CRITICAL: `docker compose` SPACE-form per CONTEXT D-04 + RESEARCH Pitfall 4. NEVER `docker-compose` dash.

       ExecStopPost=/bin/shred -u {{ sport_env_file }}
       Restart=on-failure
       RestartSec=10s
       TimeoutStartSec=600
       TimeoutStopSec=120

       [Install]
       WantedBy=multi-user.target
       ```
