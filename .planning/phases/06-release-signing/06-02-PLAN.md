SOPS field paths (extend Plan 06-01's android.*; ios.* section gets all 8 fields):
- '["ios"]["team_id"]'                          — 10-char alphanumeric, e.g. "A1B2C3D4E5" (Task 1)

- '["ios"]["provisioning_profile_base64"]'      — base64 of App Store .mobileprovision (Task 3)
- '["ios"]["provisioning_profile_uuid"]'        — UUID from `security cms -D | plutil` (Task 3)
- '["ios"]["asc_api_key_p8_base64"]'            — base64 of AuthKey_<KEYID>.p8 (EC private key, ~250 bytes) (Task 4)
- '["ios"]["asc_api_key_id"]'                   — 10-char Key ID from ASC UI (Task 4)
- '["ios"]["asc_api_issuer_id"]'                — UUID from ASC Keys page header (Task 4)

Apple portal URLs (read-only references):
- Enrollment:           https://developer.apple.com/programs/enroll/
- App IDs:              https://developer.apple.com/account/resources/identifiers/list
- Certificates:         https://developer.apple.com/account/resources/certificates/list
- Provisioning Profiles:https://developer.apple.com/account/resources/profiles/list
- ASC API keys:         https://appstoreconnect.apple.com/access/api

Apple-portal-required ordered operations (Apple enforces dependencies):
1. Enroll in Apple Developer Program → captures Team ID
2. Register Explicit App ID for com.runningecosystem.mobile
3. Generate CSR (Keychain Access.app → Certificate Assistant → Request from CA → Save to disk)
4. Upload CSR to create Apple Distribution cert; download .cer; double-click to install in Keychain
5. Export .p12 from Keychain with explicit password (32-byte random)
6. Create App Store provisioning profile bound to the App ID + cert from step 4
7. Create ASC API key with App Manager role; download AuthKey_<KEYID>.p8 (ONE-SHOT — Apple never re-shows it)

Round-trip verification commands (used in 3 smokes):
- .p12:            openssl pkcs12 -in <file>.p12 -info -nokeys -password pass:"$P12_PASS" 2>&1 | grep -q "MAC verified OK"
- .mobileprovision:security cms -D -i <file>.mobileprovision | plutil -extract UUID raw - | tr -d '\n' | grep -E '^[A-F0-9]{8}-([A-F0-9]{4}-){3}[A-F0-9]{12}$'
- .p8:             openssl ec -in <file>.p8 -text -noout 2>&1 | grep -q 'private-key'
