`ast_walk.go` (export `func WalkHandlers(rootDir string) (map[string]map[string]bool, error)`):
- For each directory `services/backend/*/internal/handler/`, walk all `*.go` files (skip `*_test.go`).
- Use `parser.ParseFile` with `ParseComments=false`.
- Walk AST looking for `*ast.CallExpr` where Fun matches `mux.HandleFunc` (SelectorExpr with X.Name="mux" and Sel.Name="HandleFunc"). Also accept the variant where the receiver is any identifier (some services use `m.HandleFunc`).
- Extract first arg if it is a `*ast.BasicLit` with `Kind=token.STRING`. Strip quotes. Validate it matches `^(GET|POST|PUT|PATCH|DELETE|HEAD|OPTIONS) /.+`. Reject and log if non-literal.
- Return `map[serviceName]map[METHOD+SPACE+PATH]bool`.

`spec_load.go` (export `func LoadSpec(yamlPath string) (map[string]bool, error)`):
- Parse YAML via `gopkg.in/yaml.v3` into a generic `map[string]any`.
- Read `paths:` map; for each path key, iterate HTTP verbs; emit `"METHOD /path"` keys.
- Return as `map[string]bool` per service.
