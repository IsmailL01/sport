# Running Ecosystem — v1.0 Scope

**Версия:** v1.0 Production Readiness
**Дата заморозки:** 2026-05-15
**Парные документы:** [.planning/REQUIREMENTS.md](../.planning/REQUIREMENTS.md), [.planning/ROADMAP.md](../.planning/ROADMAP.md), [ADR-0007](./DECISIONS/0007-v1.0-release-contract.md), [API-CONTRACT-v1.0.md](./API-CONTRACT-v1.0.md)

Этот документ — единственное место, где зафиксирован полный IN/OUT перечень
capabilities для **v1.0 closed-beta**. REQ-ID колонки ссылаются на канонические
требования в `.planning/REQUIREMENTS.md`. Любое расхождение между этим документом
и REQUIREMENTS.md — баг, фиксим в REQUIREMENTS первым.

## Цель v1.0

Tagged release `v1.0-rc.1` после 48-часового staging-soak с ≥8 реальными бегунами
(iOS + Android + ≥2 de-Googled Android), нулевыми P0/P1 issues. Закрытая бета —
TestFlight для iOS + self-hosted Android channel.

**Core value (закреплено STATE.md):** Записать пробежку → увидеть свою территорию
на карте → сохранить → видеть историю. Офлайн, точно, без сбоев фоновой записи.

## Hard rules (Out of Scope — категорическое нет)

Mirrors `.planning/REQUIREMENTS.md` §Out of Scope.

| Feature                                              | Reason                                                                                                  |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Web client (athlete-facing)                          | Mobile-first; web admin (для moderation) уже существует.                                                |
| Flutter mobile codebase                              | Archived per [ADR-0001](./DECISIONS/0001-framework-react-native.md); no parallel development.            |
| Guest mode                                           | Deferred per [ADR-0002](./DECISIONS/0002-guest-mode.md).                                                 |
| Mapbox Studio custom style                           | `outdoors-v12` устроит closed-beta.                                                                     |
| Server geographic expansion                          | Single Hetzner VPS для v1.0; multi-region — v2.0.                                                       |
| Cycling-first features                               | Sport-agnostic но running-primary; никаких cycling-specific аналитик.                                   |
| Real-time live tracking                              | Privacy + battery cost не ясны; revisit post-v1.0.                                                      |
| Smart watch native app                               | Integration через HealthKit / Health Connect / FIT когда шипнем; standalone watchOS / Garmin IQ — defer. |
